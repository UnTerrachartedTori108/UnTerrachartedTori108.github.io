Activity 1, Link 1: W3Schools — Introduction to HTML

Describe

HTML stands for HyperText Markup Language. It is the standard markup language for creating web pages. HTML describes the structure of a web page using elements that tell the browser how to display its content. HTML elements label pieces of content, such as headings, paragraphs, and links.

The <!DOCTYPE html> declaration defines the document as an HTML5 document. The <html> element is the root element of an HTML page. The <head> element contains information about the page, and the <title> element specifies the title shown in the browser tab or title bar.

The <body> element contains the visible content of the document, such as headings, paragraphs, images, hyperlinks, tables, and lists. The <h1> element defines a large heading, while the <p> element defines a paragraph. An HTML element is generally made up of a start tag, content, and an end tag.

A web browser, such as Chrome, Edge, Firefox, or Safari, reads HTML documents and displays them. Browsers do not show the HTML tags themselves; they use them to determine how to display the document.

Activity 1, Link 3: Mozilla — Getting Started with HTML

Describe

HTML, or HyperText Markup Language, tells web browsers how to structure the web pages you visit. HTML consists of elements that enclose, wrap, or mark up parts of the content to make them appear or act in particular ways. For example, tags can turn content into a hyperlink or italicize words.

HTML is written in text files called HTML documents, which usually have a .html file extension. An HTML document contains a web page’s content and specifies its structure. The most common HTML file is index.html, which is generally used for a website’s home page. Websites may also have subfolders containing their own index.html files.

A complete element consists of an opening tag, content, and a closing tag. The opening tag contains the element’s name within angle brackets. The closing tag uses the same name, preceded by a forward slash, to mark where the element ends.

Attributes provide extra information about an element. For example, the class attribute provides a name that can be used to target an element with CSS styles or JavaScript. An attribute is written after the element name, with a space between them. It consists of an attribute name, an equals sign, and a value wrapped in quotation marks. Multiple attributes should be separated by spaces.

Activity 2, Link 1: Shay Howe — Building Your First Web Page

Describe

HTML, or HyperText Markup Language, gives content structure and meaning by defining it as headings, paragraphs, images, and other types of content. CSS, or Cascading Style Sheets, is used to style the appearance of content, including its fonts and colors. HTML and CSS are independent languages: HTML represents content, while CSS represents its appearance.

Elements define the structure and content of objects on a page. Common examples include headings, from <h1> through <h6>, paragraphs using <p>, and elements such as <a>, <div>, <span>, <strong>, and <em>.

Angle brackets around an element’s name create a tag. Tags commonly appear in opening and closing pairs. An opening tag marks the beginning of an element, such as <div>. A closing tag marks its end, such as </div>. The content between the tags belongs to that element. For example, an anchor link uses an opening <a> tag and a closing </a> tag.

Attributes provide additional information about an element. Common attributes include id, which identifies an element; class, which classifies an element; src, which specifies the source of embedded content; and href, which provides a hyperlink reference. Attributes are written inside the opening tag after the element name, usually as a name followed by an equals sign and a quoted value.
