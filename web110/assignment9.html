Assignment 9 Paragraph. HTML, short for Hyper Text Markup Language is a markup language that tells web browsers how to structure the web pages you visit. HTML consists of a series of elements, which you use to enclose, wrap, or mark up different parts of content to make it appear or act in a certain way. The enclosing tags can make content into a hyperlink to link to another page, italicize words, etc. I learned that the most common HTML file is index.html, which is generally used to contain a website's home page content. It's also common to see subfolders containing their own index.html files, so websites can have multiple index files in different places.
